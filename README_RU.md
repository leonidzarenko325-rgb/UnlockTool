
# UnlockTool

**UnlockTool** — это системная утилита для Windows, предназначенная для мониторинга, обслуживания, диагностики и восстановления операционной системы через единый графический интерфейс.

Приложение объединяет инструменты управления системой, диагностики, очистки и восстановления Windows.

## Возможности

### Главная
- Централизованный обзор приложения.
- Быстрый доступ к основным инструментам.
- Удобная навигация между разделами.

### Диспетчер задач
- Просмотр запущенных процессов.
- Мониторинг информации о процессах и использовании ресурсов.
- Определение критичности процессов.
- Приостановка, возобновление и завершение процессов.
- Открытие расположения файлов процессов.
- Поиск и обновление списка процессов.

### Управление пользователями
- Просмотр локальных учётных записей Windows.
- Управление доступными параметрами учётных записей.
- Доступ к инструментам управления пользователями.

### Диагностика
- Доступ к системным диагностическим инструментам.
- Просмотр необходимой информации о Windows.
- Дополнительные средства устранения неполадок.

### Восстановление системы
- Доступ к инструментам восстановления Windows.
- Проверка системы с помощью SFC и DISM.
- Использование инструментов проверки дисков.
- Управление отдельными параметрами восстановления.
- Переход в среду восстановления Windows.

### Очистка системы
- Удаление временных файлов.
- Очистка эскизов и файлов кэша.
- Очистка корзины.
- Очистка DNS-кэша.
- Просмотр информации об очистке перед выполнением выбранных операций.

### Монитор BSOD
- Отслеживание событий синего экрана Windows.
- Просмотр обнаруженных системных сбоев.
- Доступ к диагностической информации о сбоях.
- Экспорт диагностических отчётов.

### Менеджер реестра
- Просмотр поддерживаемых параметров реестра Windows.
- Просмотр и изменение поддерживаемых значений реестра.
- Доступ к инструментам восстановления реестра.

### Менеджер дисков
- Просмотр информации о дисках и томах.
- Просмотр сведений о разделах и файловых системах.
- Проверка свободного места.
- Доступ к поддерживаемым операциям управления и диагностики дисков.

### Дополнительные инструменты
- Управление автозагрузкой.
- Инструменты восстановления загрузчика.
- Восстановление стандартного оформления Windows.
- Дополнительные функции обслуживания системы.

## Интерфейс

UnlockTool обладает современным тёмным интерфейсом с боковой панелью навигации, отдельными страницами инструментов и встроенным разделом настроек.

Поддерживаются:
- Английский язык интерфейса.
- Русский язык интерфейса.
- Сохранение выбранного языка.
- Единый визуальный стиль всех разделов приложения.

## Системные требования

- Операционная система Windows.
- Для выполнения некоторых операций могут потребоваться права администратора.
- Работа отдельных функций восстановления зависит от компонентов Windows и конфигурации системы.

Совместимость с отдельными версиями Windows и средами восстановления может отличаться.

## Поддерживаемые языки

- Английский
- Русский

## Предупреждение о безопасности

UnlockTool выполняет операции, которые могут изменять параметры Windows, значения реестра, системные файлы и другие компоненты операционной системы.

Для некоторых операций требуются права администратора.

Перед выполнением операций внимательно проверяйте выбранные действия. Перед существенными изменениями системы рекомендуется создавать резервные копии или точки восстановления.

Вы используете приложение на собственный риск.
