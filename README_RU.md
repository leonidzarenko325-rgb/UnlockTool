
# UnlockTool 1.0.1

**Утилита для обслуживания и восстановления Windows — C++ / Win32 / GDI+**

UnlockTool — настольное приложение для обслуживания, диагностики и восстановления Windows. Этот репозиторий содержит исходный проект Visual Studio с исходной архитектурой приложения и интегрированными дополнительными модулями.

## Реализованные и подключённые разделы

- **Task Manager:** список процессов, сведения о критических процессах, приостановка, возобновление и завершение процессов с защитой критических процессов, контекстное меню для открытия расположения файла, переход к штатной вкладке автозагрузки Windows.
- **Users:** модуль управления локальными пользователями.
- **Diagnostics:** сведения о системе, проверка SFC, службы Windows и Event Viewer.
- **Recovery:** сброс Microsoft Store, переход к настройкам Windows Update, SFC, DISM, CHKDSK, Advanced Startup / WinRE и включение UAC с созданием `.reg`-резервной копии.
- **System Cleanup:** очистка временных файлов пользователя, кэша миниатюр, Корзины и DNS-кэша. Очистка Корзины требует подтверждения и является необратимой.
- **BSOD Monitor:** чтение событий BugCheck из System Event Log, переход в Reliability Monitor и Event Viewer, открытие папки дампов, экспорт отчётов в TXT и HTML. При запуске приложения отображается уведомление о новой записи; также доступна настройка автозапуска.
- **Registry:** работа с параметрами Shell, Userinit, CmdLine, AppInit_DLLs, SetupType и EnableCursorSuppression. Перед записью проверяется тип значения; доступны резервное копирование и откат изменений в текущем сеансе.
- **Disk Manager:** информация о томах, файловых системах, общем и свободном объёме, модели физического диска, стиле разделов GPT/MBR и прогнозе SMART failure prediction при поддержке накопителя. Доступны запуск CHKDSK, Disk Management и `manage-bde -status`.
- **Settings:** переключение русского и английского интерфейса, настройки уведомлений и автозапуска, сведения о приложении.

## Важные ограничения текущей сборки

- Структура исходников и связи проекта проверены, однако собрать и запустить Win32-приложение в Linux-среде невозможно. Перед использованием необходимо выполнить реальную сборку в Visual Studio и протестировать приложение на отдельной системе или виртуальной машине.
- Поддержка WinRE пока частичная. Онлайн-команды SFC и DISM не запускаются из WinRE, чтобы случайно не обслуживать сам образ среды восстановления. Автоматический выбор установленной Windows и обслуживание офлайн-системы ещё не реализованы.
- Работа с реестром выполняется в активном `HKLM`. Автоматическая загрузка офлайн-hive `SYSTEM` или `SOFTWARE` пока не реализована.
- Резервные копии параметров страницы Registry и возможность отката хранятся в памяти до закрытия приложения. Для UAC создаётся отдельный `.reg`-файл в `%LocalAppData%\UnlockTool\RegistryBackups`.
- BSOD Monitor формирует общий TXT- или HTML-отчёт по найденным событиям BugCheck. Отдельные отчёты для каждого инцидента, фильтры и сохранение пользовательской сортировки ещё требуют доработки.
- Disk Manager показывает SMART-прогноз только в том случае, если накопитель и драйвер поддерживают соответствующий IOCTL. Для смены букв томов открывается штатная оснастка Disk Management. Проверка состояния BitLocker запускает `manage-bde`; разблокировка зашифрованного тома передаётся штатным средствам Windows.
- Полная совместимость с Windows 10 1607, архитектурой x86 и WinRE отдельно не подтверждена.

## Структура проекта

- `UnlockTool/UnlockTool.vcxproj` — проект C++.
- `UnlockTool/UnlockTool.rc` и `UnlockTool/UnlockTool.ico` — ресурсы приложения.
- `main.cpp` — главное окно, навигация и интеграция модулей.
- `RegistryRepair.*`, `RegistryPage.*` — работа с параметрами реестра.
- `Cleanup.*` — инструменты очистки.
- `TaskManager.*` — управление процессами.
- `Users.*`, `UsersPage.*` — управление пользователями.
- `DiskManager.*`, `DiskManagerPage.*` — работа с дисками и томами.
- `BSODMonitor.*`, `BSODMonitorPage.*` — история событий BugCheck.

## Безопасность

Функции восстановления и изменения системных параметров могут повлиять на работу Windows. Перед их использованием рекомендуется создать актуальную резервную копию важных данных. Внимательно проверяйте выбранные операции и тестируйте приложение в виртуальной машине или другой безопасной среде.
