# UnlockTool 2.0.0

**Windows maintenance and recovery utility — C++ / Win32 / GDI+**

Этот архив содержит исходный проект Visual Studio. В нём сохранена исходная архитектура приложения и интегрированы дополнительные модули.

## Открытие и сборка

1. Установите **Visual Studio 2026** с компонентом **Разработка классических приложений на C++**.
2. Убедитесь, что установлен Windows 10 SDK.
3. Откройте `UnlockTool.sln` или `UnlockTool.slnx`.
4. Выберите `Release` и `x64`.
5. Выполните **Build → Build Solution**.
6. Запустите собранный `UnlockTool.exe`. Проект запрашивает права администратора через manifest.

Проект использует toolset `v145` и стандарт C++20. В конфигурациях доступны `Win32` и `x64`.

## Реализованные и подключённые разделы

- **Task Manager:** список процессов, сведения о критических процессах, приостановка/возобновление/завершение с защитой критических процессов, контекстное меню расположения файла, переход к вкладке автозагрузки Windows.
- **Users:** существующий модуль управления локальными пользователями.
- **Diagnostics:** System Information, проверка SFC, службы Windows и Event Viewer.
- **Recovery:** Microsoft Store reset, Windows Update settings, SFC, DISM, CHKDSK, Advanced Startup / WinRE и включение UAC с `.reg`-резервной копией.
- **System Cleanup:** временные файлы пользователя, кэш миниатюр, Корзина и DNS-кэш. Очистка Корзины требует подтверждения и необратима.
- **BSOD Monitor:** чтение событий BugCheck из System Event Log, переход в Reliability Monitor/Event Viewer, открытие папки дампов, экспорт TXT и HTML. Есть уведомление о новой записи при запуске приложения и настройка автозапуска.
- **Registry:** Shell, Userinit, CmdLine, AppInit_DLLs, SetupType и EnableCursorSuppression. Запись выполняется с проверкой типа значения; доступны резервная копия и откат в текущем сеансе.
- **Disk Manager:** тома, файловые системы, объём/свободное место, модель физического диска, стиль GPT/MBR и SMART failure prediction при поддержке накопителя; запуск CHKDSK, Disk Management и `manage-bde -status`.
- **Settings:** русский/английский интерфейс, настройки уведомлений и автозапуска, сведения о приложении.

## Важные ограничения текущей сборки

- Исходники проверены на целостность структуры и связей проекта, но **собрать и запустить Win32-приложение в этой Linux-среде невозможно**. Перед использованием нужен реальный Build в Visual Studio и тест на отдельной системе/виртуальной машине.
- Режим WinRE пока частичный: онлайн-команды SFC/DISM не запускаются из WinRE, чтобы случайно не обслуживать сам образ восстановления. Автоматический выбор и обслуживание офлайн-установки Windows ещё не реализованы.
- Реестр сейчас работает с активным `HKLM`, а не с автоматически загруженным офлайн SYSTEM/SOFTWARE hive.
- Резервные копии параметров страницы Registry и откат хранятся в памяти до закрытия приложения. Для UAC создаётся отдельный `.reg`-файл в `%LocalAppData%\UnlockTool\RegistryBackups`.
- BSOD Monitor формирует общий TXT/HTML-отчёт по найденным BugCheck-событиям. Отдельные отчёты на каждый инцидент, фильтры и сохранение пользовательской сортировки ещё требуют доработки.
- Disk Manager показывает SMART-прогноз только если накопитель и драйвер поддерживают соответствующий IOCTL. Смена букв томов открывает штатное Disk Management; BitLocker status запускает `manage-bde`, а открытие зашифрованного тома передаёт разблокировку Windows.
- Полная совместимость с Windows 10 1607, x86 и WinRE отдельно не подтверждена.

## Структура

- `UnlockTool/UnlockTool.vcxproj` — проект C++.
- `UnlockTool/UnlockTool.rc` и `UnlockTool/UnlockTool.ico` — ресурсы приложения.
- `main.cpp` — главное окно, навигация и интеграция модулей.
- `RegistryRepair.*`, `RegistryPage.*` — работа с параметрами реестра.
- `Cleanup.*` — очистка.
- `TaskManager.*` — процессы.
- `Users.*`, `UsersPage.*` — пользователи.
- `DiskManager.*`, `DiskManagerPage.*` — диски и тома.
- `BSODMonitor.*`, `BSODMonitorPage.*` — история BugCheck.

Перед использованием функций восстановления и изменения системных параметров рекомендуется иметь актуальную резервную копию важных данных.
